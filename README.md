项目名称：贪吃蛇小游戏（畅通无阻） | C++/SFML

技术栈： C++、SFML 2.6.0、Visual Studio、面向对象编程、事件驱动、固定时间步长游戏循环

项目描述：
基于 C++ 与 SFML 图形库开发 2D 贪吃蛇游戏，采用面向对象与事件驱动架构，实现菜单、游戏、暂停、选项、帮助、关于、结束等多界面切换，以及蛇移动、水果生成、碰撞检测、分数统计、暂停恢复等完整游戏功能。

主要工作：

采用 OOP 设计游戏架构，抽象 Screen 基类并派生 MenuScreen、GameScreen、PauseScreen、OptionScreen、GameOverScreen、HelpScreen、AboutScreen 等界面；设计 Snake、Fruit、Button、Grid 等类，明确继承与协作关系。

基于事件驱动实现输入系统，监听键盘方向键、鼠标左/右键及窗口关闭事件；实现按钮悬停与点击检测，支持菜单和游戏内交互。

设计并实现游戏主循环，使用 sf::Clock 与固定时间步长 Game::TimePerFrame 控制更新频率，按“输入处理—逻辑更新—渲染”流程驱动游戏，通过 window.clear()、draw()、display() 完成刷屏渲染。

实现核心玩法：蛇的移动与增长、随机水果生成、蛇与水果碰撞检测、边缘与自身碰撞检测、分数统计及暂停/恢复状态切换。

完成 SFML 环境配置、编译链接与调试，排查移动逻辑、碰撞检测、渲染闪烁等问题，并在不同窗口尺寸下测试运行效果。

项目成果：
完成可运行的 2D 贪吃蛇游戏，具备完整游戏流程和多界面交互；加深了对 C++ 面向对象设计、事件驱动编程、SFML 图形渲染和游戏循环机制的理解。
